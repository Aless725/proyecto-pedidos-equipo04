# Sistema de gestion de pedidos, clientes y productos

Repositorio estructurado para el control y gestion modular de clientes, pedidos y productos de la aplicacion.

## Estructura del Proyecto

El proyecto se encuentra organizado en las siguientes carpetas y archivos dentro del directorio fuente:


Modulos del Sistema
Clientes: Contiene la interfaz web y la logica en JavaScript para la administracion de los clientes.

Pedidos: Modulo hibrido que incluye interfaz web, script de control frontend y un script en Python para la logica de procesamiento de pedidos.

Productos: Contiene la interfaz principal del catalogo y sus respectivos estilos visuales en CSS.

Requisitos y Ejecucion
Clona el repositorio en tu entorno local.

Para ejecutar las interfaces web, abre los archivos index.html correspondientes en un navegador o utiliza un servidor local.

Para ejecutar el procesamiento de pedidos en Python, asegurate de tener instalado Python e ingresa al directorio correspondiente:

python src/pedidos/pedidos.py
